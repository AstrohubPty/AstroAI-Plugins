# Material style colour schemes

The Material style (clean flat surfaces with gentle elevation): Indigo, Teal, Slate, Paper and Sand.

A theme is only colours: it has no code and no CSS, so installing one asks for nothing and needs no restart. Pick the schemes in
Settings → Appearance. To make your own, copy `theme.yaml` and change the colours.

AstroAI keeps a copy of this folder in `vendor/plugins/themes-material` for its own tests and for simulate's demo; change it here first,
then refresh that copy.
