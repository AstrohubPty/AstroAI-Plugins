# Glass style colour schemes

The Glass style (frosted, translucent panels over a colour wash): Aurora, Ocean, Sunset, Twilight and Frost.

A theme is only colours: it has no code and no CSS, so installing one asks for nothing and needs no restart. Pick the schemes in
Settings → Appearance. To make your own, copy `theme.yaml` and change the colours.

AstroAI keeps a copy of this folder in `vendor/plugins/themes-glass` for its own tests and for simulate's demo; change it here first,
then refresh that copy.
